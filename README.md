# Pozitron Academy — Language Learning & Spaced Repetition Platform

Pozitron Academy is an open, community-driven language learning ecosystem designed to make vocabulary acquisition permanent and effortless.

It combines:
1. **SuperMemo-2 (SM-2)** scientifically proven spaced repetition algorithm.
2. **Interactive Book Reader** with instant 1-click word translation and auto-flashcard creation.
3. **Gamified XP & Streaks** with Telegram Bot integration.

---

## Tech Stack
- **Backend**: Python 3.11+, FastAPI, aiogram 3.x (Async Telegram Bot)
- **Database**: PostgreSQL / SQLite (Development) + Redis
- **Algorithms**: SuperMemo-2 (SM-2) Interval Calculation
- **Frontend**: Progressive Web App (PWA) / HTML5, Tailwind CSS
